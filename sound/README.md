Put the game sound files here:

  sound/start.mp3   plays before the game starts (the 3-2-1 countdown waits for it to finish)
  sound/during.mp3  loops while playing; it is sped up as levels get faster

Any audio format works: mp3, m4a, ogg, opus, wav, webm, flac.
Only the name matters (start.* and during.*).
With no files here the game falls back to countdown beeps and plays no music.
